# Sharpen Proposal Quality

## Why

A structurally perfect but intellectually hollow proposal currently sails through the entire pipeline with zero complaints: check.py reads no prose meaning, review enumerates findings but renders no verdict, write pads thin seeds into well-sounding drafts, and ideate converges on generic content. A student probing for a shortcut ends with a "clean" proposal that has no potential as a thesis — and no tool ever said so. Generated proposals also accumulate low-information sentences no rule forbids, and no skill carries an explicit neutral-tone rule for chat output.

## What Changes

- **Five named substance tests** land in the prose guidance: delta, falsifiability, swap (anti-generic), method-fit, and executability (concrete actionable goals, named objects of study, feasible in the stated months). They anchor every semantic depth judgment.
- **Information-density rule** in the guidance: every sentence must carry information essential to this thesis — no scene-setting, no truisms, no restated obvious.
- **Page limit** gets a default (5 pages, generous, warning-level) and a consumer: `page_limit` today is a documented override key that nothing reads.
- **check** gains a word-count-based estimated-pages warning and scopes its verdict line explicitly: "mechanically clean" says nothing about substance — run review.
- **review** renders a three-tier verdict (`ready` / `needs revision` / `no viable thesis core`) at the top of the review file and in chat, citing failed substance tests by name; concreteness/executability join its judgment areas.
- **write** gains a substance gate (no-generate: hollow material becomes a TODO or an omitted section, stated plainly — never generic prose) and a binding density deletion pass after each writing pass.
- **ideate** raises its convergence bar: seeding requires concrete student-contributed specifics on the five tracked aspects; generic-only content triggers the swap test voiced Socratically; persistent genericity routes to the existing impasse path.
- **Voice block**: a byte-identical neutral-tone block in all eight SKILL.md files (never praise the student or their artifacts, never self-congratulate, short precise chat messages), enforced offline by extending the header-pattern test.

Eval instrumentation proving these gates fire is deliberately split into the follow-up change `prove-quality-gates`.

## Capabilities

### New Capabilities

(none)

### Modified Capabilities

- `guidance-model`: adds the five substance tests, the information-density rule, and the default page limit to the semantic guidance; page limit joins the mechanically checkable skeleton.
- `skill-check`: estimated-pages warning (override-aware); verdict line explicitly scopes what "clean" claims.
- `skill-review`: three-tier verdict citing failed substance tests; concreteness/executability as judgment areas.
- `skill-write`: substance gate (no-generate on hollow material) and binding density deletion pass.
- `skill-ideate`: concreteness gate at convergence; swap-test Socratic move; generic sessions end via impasse, never a generic seed.
- `skill-packaging`: uniform opening structure grows a fourth byte-identical block (voice); offline enforcement extended.
