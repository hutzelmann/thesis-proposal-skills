# README demo

The three collapsible session excerpts at the top of the top-level README are a **curated condensation of a real agent session** — shortened, never invented. `harvest.log` is the trimmed raw output of that session; every paper, quote and result shown traces back to it.

## Files

| File | Role |
|---|---|
| `harvest.log` | Audit trail: trimmed raw output of the session the README demo condenses |

The demo text itself lives in `README.md` at the repository root — there is nothing to render or regenerate.

## Editing the demo

Edit the `<details>` blocks in the top-level `README.md` directly. Keep the three beats aligned with the workflow the skills teach (idea → literature → draft, check, publish), and keep each block short enough to read in one screen.

Keep the content traceable: if you show new agent output, run a real session on a synthetic topic and extend `harvest.log` — never invent papers, results, or excerpts. The demo topic is synthetic and carries no personal data; keep it that way.
