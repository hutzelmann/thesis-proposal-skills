The reproduction is a workspace of its own, shaped like the user's: write the reduced file to `bug-report/repro/input/input.md` — `input` stands in for the slug, so the topic's name never reaches the report — add a copy of `guidelines.md` to `bug-report/repro/` only when the defect depends on it, and write the exact command, run from `bug-report/repro/`, to `bug-report/repro/command.txt`.
