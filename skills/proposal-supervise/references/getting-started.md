# Getting-started blurb for the feedback letter

Quoted verbatim into every letter, in the section matching the letter's language. Keep the two sections translations of each other; the letter carries exactly one of them.

## English

> **Continuing from here.** The attached file is your proposal in a plain-text format that a set of free writing tools can work with. They run inside an AI assistant (for example Claude Code, Cursor, or Codex — if you have never used one, the guide at https://github.com/hutzelmann/thesis-proposal-skills explains the setup from zero). Once the assistant is installed, open it in a new folder, run `npx skills add hutzelmann/thesis-proposal-skills`, place the attached file in that folder, and say "help me improve my proposal". The tools follow the same guidelines this feedback is based on, and every decision about your thesis stays yours.

## Deutsch

> **So geht es weiter.** Die angehängte Datei ist Ihr Exposé in einem Textformat, mit dem eine Sammlung kostenloser Schreibwerkzeuge arbeiten kann. Sie laufen in einem KI-Assistenten (zum Beispiel Claude Code, Cursor oder Codex — falls Sie noch nie einen benutzt haben, erklärt die Anleitung unter https://github.com/hutzelmann/thesis-proposal-skills die Einrichtung von Grund auf). Nach der Installation öffnen Sie den Assistenten in einem neuen Ordner, führen `npx skills add hutzelmann/thesis-proposal-skills` aus, legen die angehängte Datei in diesen Ordner und sagen "Hilf mir, mein Exposé zu verbessern". Die Werkzeuge folgen denselben Richtlinien wie dieses Feedback, und jede Entscheidung über Ihre Thesis bleibt bei Ihnen.
